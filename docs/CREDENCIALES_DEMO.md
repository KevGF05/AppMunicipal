# Credenciales de demostración

## Administrador

```text
admin@municipalidad.hn
Admin123*
```

## Técnico inicial en una base de datos nueva

```text
Nombre: Carlos Mejía
Correo: carlosm@pmunicpalidad.hn
Contraseña: Tecnico123*
```

## Técnicos creados por el administrador

El correo se genera automáticamente con:

```text
nombre + primera letra del apellido + @pmunicpalidad.hn
```

Todos los técnicos nuevos usan temporalmente:

```text
Tecnico123*
```

Si la base de datos ya tenía técnicos de una versión anterior, sus cuentas se conservan. Al editarlos desde **Administrar técnicos**, se les genera el correo con el formato nuevo.

Estas credenciales son únicamente para la presentación académica. Antes de publicar la aplicación debe implementarse una política de contraseñas individuales.
